# Answers

Write short answers in your own words.

1. What is a GitHub repository used for?

   Answer: A GitHub repository is used to store and manage a project's files, track their complete revision history, and collaborate with others in a central location.

2. Why might you create a branch before changing a project?

   Answer: You create a branch to work on new features or bug fixes safely without affecting the stable main codebase until the changes are tested and ready.

3. What is the purpose of a pull request?

   Answer: The purpose of a pull request is to propose changes from one branch to another, allowing collaborators to review, discuss, and test the code before merging it into the project.

4. When could an issue be useful in a project?

   Answer: An issue is useful for reporting bugs, requesting new features, asking questions, or organizing and tracking project tasks and discussions.
